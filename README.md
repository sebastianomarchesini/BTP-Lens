# BTP Lens

A free, open-source, **read-only** CLI that scans a Cloud Foundry landscape on SAP BTP. It reports app inventory, runtime health, outdated or vulnerable libraries, and security posture as an offline HTML report, JSON, CSV and SARIF.

> **Status:** under construction. v0.1 is in progress, and nothing is published to npm yet.

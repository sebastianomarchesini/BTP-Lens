BTP Lens

The free, read-only health check for your Cloud Foundry landscape on SAP BTP. One command, five minutes, nothing leaves your machine. 

npx btp-lens

See a sample report → Source on GitHub → Guide for non-developers →

Read-only, by construction

The client can only send GET requests to the Cloud Foundry API. A test proves it. The Space Auditor role is enough.

Nothing leaves your machine

Allow-listed hosts in one file, no telemetry, and a report whose Content Security Policy forbids any connection.

Every finding says what to do

Runtime end of life, deprecated stacks, idle apps, outdated SAP libraries, known CVEs, each with a remediation and a link.

For administrators too

Guided mode asks four questions and signs you in with your company login. No cf CLI, no flags, no YAML.

The sample report on this page was generated from synthetic test fixtures, not from a real landscape. The tool is in development towards v0.1.0; check the repository for the current state.

# Pre-release audit of 0.1.0 (2026-10-11)

Record of the multi-agent audit run on the release branch before tagging `v0.1.0`, kept so that the work can be picked up again without repeating it. Eleven independent auditors each reviewed one dimension of the release at commit `8408dd0`; a dedup pass merged their findings; an adversarial verification (three lenses per finding: reproduce, refute, impact) was started and stopped early to save budget. The fixes landed in commit `9d5199d` on the release branch.

## Numbers

- Raw findings: 75 from 11 auditors; unique after dedup: 59 (47 non-nit, 12 nits).
- Verification completed for 6 of 47 non-nit findings before the run was stopped; the rest are listed below as *not yet verified*. Every finding marked *Fixed* was re-checked by hand against the code before fixing, and the fix is covered by a unit, fixture or Playwright test where one applies.

## How to continue

- The verification of the remaining findings can run with a cheaper model: in the workflow script, add `model: 'sonnet'` (or `'haiku'`) to the `agent()` calls inside `verify()`, then resume with `resumeFromRunId: 'wf_cb2a86d2-773'`; the auditors and the dedup step replay from the journal, only the verifiers run. The journal lives in the session's container, so if that is gone, start from the table below instead: each *not yet verified* row names the file, the claim and the evidence the auditor gave.
- Rows marked *Open* are small and were deliberately left for 0.1.1 or a good-first-issue.
